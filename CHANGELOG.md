# Changelog

## 1.1.0 — 2026-09-06

- Shipwreck Desk workspace with independent 3D/Image Editor task tabs.
- 48 procedural presets, six categories, eight append-only recipes, favorites and searchable swatches.
- Live weathering, directional/waterline placement, object/world/UV fields, box-projected source maps, and editable color/roughness/bump variation.
- Twelve copy-on-edit image filters, generated UV masks, one-step image restore/A-B, height-to-normal tools and eight native brush setting presets.
- Real Cycles CPU material baking to PNG channels and ORM, with manifests, unique destinations, source preservation and failure cleanup.
- Fix unsaved pixel loss during color-space reassignment, mask duplication and image export.
- Handle Blender 5.x brush/falloff API changes.
- Reproducible extension builder; Python, installed-copy, UI and Blender 4.5.11/5.2.1 integration checks.

## 1.0.0 — 2026-07-16

- Initial Blender 4.5 LTS release.
- Unlimited ordered PBR layers with independent grayscale UV masks.
- Native Reveal, Hide, and Soften texture-paint workflow.
- Base color, roughness, metallic, normal, height, AO, and emission channels.
- Selected-face material assignment and paint guarding.
- PBR set importer, UV audit, ship-interior starter, channel previews, mask persistence/export, single-user isolation, and graph repair/restore.
